# Report status

`evaluation.json`, `evaluation_heldout.json` and `evaluation_coverage.json`
are current-code results regenerated from the saved gold files. They are the
only JSON score reports cited by `EVALUATION.md`.

The two `*_blind.json` files are legacy artefacts from an earlier working
state. This repository does not contain the timestamped labels and frozen code
needed to verify their claimed historical chronology, so I do not cite or rely
on them in the submission.
