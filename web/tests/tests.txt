## Test 1 - Inspect the interactive synthetic redaction walkthrough [sanity]
Viewport: desktop (1280x800)
Covers: source-view rendering, redacted-output rendering, privacy-safe audit-trace rendering
Description: Verifies a reviewer can inspect each stage of an explicitly synthetic transformation without exposing the submitted prospectus.

Steps:
1. Open the reviewer console
2. In the "Inspect a transformation" panel, confirm Source view is selected and detected values are highlighted
3. Select "Redacted output" and confirm a stable fake replacement is visible
4. Select "Audit trace" and confirm source hashes, detector names and replacements are displayed

Expected: Every interactive view renders, and the walkthrough is visibly marked as a static synthetic demo rather than the submitted prospectus.
